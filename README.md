# University Kart Royale (Retro Remix)

A browser-based 2D retro kart racing game built for a first-year hackathon under the **Retro Remix** track (*Old Tech, New Tricks*)[cite: 7, 10, 11]. Players race around a circuit inspired by university locations in a fast, local browser build[cite: 7, 10].

## The Twist
Classic arcade kart racing reimagined with a retro aesthetic and university-inspired track landmarks[cite: 7, 11]—scoped intentionally as a playable, self-contained browser demo for a 7-hour hackathon sprint.

## Planned Core Features (MVP)
- **Controllable Kart:** Accelerate, brake/reverse, and steer smoothly around the circuit.
- **University-Inspired Track & Boundaries:** Circuit layout with wall/off-track collision handling so players stay on course[cite: 7, 10].
- **Race Loop & HUD:** Countdown, lap counter, race timer, and a finish/winner screen.
- **One Extra Feature:** [AI rival OR speed boost—update once chosen][cite: 10].

## Tech Stack
- **Game Framework:** Phaser 3[cite: 10]
- **Language & Build Tool:** JavaScript + Vite[cite: 10]
- **Version Control & Docs:** Git / GitHub (`README.md` and `PROJECT_NOTES.md`)[cite: 10, 12]
